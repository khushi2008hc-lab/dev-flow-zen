## ✨ Features

- **⏱️ Precision Pomodoro Engine:** Circular SVG progress ring tracking focus sessions with time-remaining calculations.
- **🎧 Procedural Ambient Soundscapes:** Built using the Web Audio API with zero external audio assets:
  - *Cyber Rain:* Pink noise filtered through lowpass biquad nodes.
  - *Cafe Ambience:* FM-modulated warm frequency hums.
  - *Alpha 432Hz:* Binaural delta/alpha frequency tone generator for deep focus.
- **📋 Drag-and-Drop Kanban Board:** Persistent state management with column sorting across Backlog, In Flight, and Shipped.
- **📝 Code Scratchpad:** LocalStorage-backed auto-saving scratchpad for fast architectural notes.
- **🟩 30-Day Activity Heatmap:** GitHub-styled habit tracking matrix.

## 🛠️ Tech Stack

- **Audio:** Web Audio API (Synthesizers & Noise Filters)

- **Styling:** CSS3 Custom Properties, Glassmorphism, Responsive Grid
